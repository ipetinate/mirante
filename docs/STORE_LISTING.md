## Description

Your band, your face.

Mirante is a watch-face studio for Xiaomi smart bands. Start with a blank project or bring in a compatible Mi Create / EasyFace project, then shape every detail in a visual editor made for the small screen on your wrist.

DESIGN WITH CONTROL

Add images, digital time, activity data, arcs, pointers, analog elements, and more. Arrange layers, lock elements in place, and fine-tune their size and position. Crop imported images and compress assets when building to help keep your face package compact.

PREVIEW AND BUILD LOCALLY

See your design at the selected band's screen dimensions. Build a compiled `.bin` directly in Mirante—no cloud build required. Keep your editable project separate from the compiled face so you can continue refining your design.

WORK ON IPHONE OR MAC

Use the Mac app as a spacious design and build workspace, or create and edit on iPhone. Projects use Mirante's native format for the best support, with `.fprj` import and export available for Mi Create / EasyFace compatibility.

INSTALL FROM IPHONE

Connect to a compatible band over Bluetooth and install a compiled face from your iPhone. The band must remain paired with Mi Fitness, and installation requires the band's valid authentication key. Mirante does not install faces to the watch from the Mac app.

SHARE WITH THE COMMUNITY

Explore community faces and publish your own through Mirante's GitHub-backed store. Publishing is optional and requires GitHub authorization. Share only designs and assets you have permission to distribute.

Mirante is an independent community project and is not affiliated with Xiaomi. Compatibility depends on the band model, firmware, project features, and compiled face format. Always check a face on your own device before relying on it.
